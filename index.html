드래그로 위치 지정

번호가 붙은 원을 원하는 곳에 놓으면 그 자리가 클릭 지점이 됩니다. 원은 여러 개 추가할 수 있습니다.

간격과 무작위 편차

클릭 간격을 ms 단위로 정하고, 무작위 편차를 더해 사람이 누르는 듯한 리듬을 만들 수 있습니다.

키보드로 바로 제어

F8로 시작하고 정지하고, Esc로 즉시 멈춥니다.

설치는 1분이면 끝나요

  1. ZIP 파일 압축 풀기

    다운로드한 파일을 풀면 autoclicker 폴더가 생깁니다.

  2. 확장 프로그램 페이지 열기

    크롬 주소창에 아래 주소를 붙여넣고, 오른쪽 위의 개발자 모드를 켜세요.

    chrome://extensions
  3. 압축해제된 확장 프로그램 로드

    ‘압축해제된 확장 프로그램을 로드합니다’를 누르고 autoclicker 폴더를 선택하세요.

  4. 아이콘 클릭해서 사용

    클릭을 넣을 페이지에서 툴바의 확장 프로그램 아이콘을 누르면 패널이 열립니다.
